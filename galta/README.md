# Galta

Galta provides a series of reusable Java libraries. The whole project is organized as a mono repo, made of Maven modules.  


## Why Galta?  
People in the French Alps used to speak their own language, called 'patois'.  In Haute Savoie, a 'galta' means an attic, or a storeroom under the roof. See: [https://www.hautesavoiephotos.com/lexique.htm](https://www.hautesavoiephotos.com/lexique.htm).  
This is what this repository is about: a place where to find several unrelated Java utilities...
