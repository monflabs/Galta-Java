Welcome to ResourceFS

A powerful filesystem implementation for accessing classpath resources through the standard Java NIO.2 API

🚀 Standard API

Use the familiar java.nio.file.Files API to work with resources - no special APIs to learn!

📁 Directory Navigation

Browse and navigate resource directories just like regular filesystems with full support for tree walking.

🔍 Pattern Matching

Use glob and regex patterns to find resources quickly and efficiently.

📋 Manifest-Based

Simple manifest file lists all available resources - easy to generate at build time.

🔒 Read-Only

Resources are immutable and read-only, ensuring safety and consistency.

⚡ High Performance

Efficient resource loading with minimal overhead using standard ClassLoader APIs.
