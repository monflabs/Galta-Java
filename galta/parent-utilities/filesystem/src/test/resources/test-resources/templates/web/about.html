About ResourceFS

ResourceFS is a custom FileSystem implementation that provides read-only access to classpath resources through the standard Java NIO.2 API.

Why ResourceFS?

Java's ClassLoader can load resources, but it has limitations:

  • No way to enumerate resources
  • No directory structure navigation
  • Returns InputStream, not Path API

ResourceFS solves these problems by using a manifest file to enumerate resources and wrapping them in a full FileSystem implementation.

Key Features

  • Standard java.nio.file.Files API
  • Directory navigation and tree walking
  • Pattern matching (glob and regex)
  • Manifest-based resource enumeration
  • Configurable base path and ClassLoader

Example Usage

Map<String, Object> env = Map.of(
    ResourceFileSystemProvider.BASE_PATH_PARAM, "config/"
);

try (FileSystem fs = provider.newFileSystem(uri, env)) {
    Path config = fs.getPath("/app.properties");
    Properties props = new Properties();
    try (InputStream in = Files.newInputStream(config)) {
        props.load(in);
    }
}

Use Cases

ResourceFS is perfect for:

  • Application configuration files
  • HTML/email templates
  • Static web assets
  • Test fixtures
  • Embedded documentation
