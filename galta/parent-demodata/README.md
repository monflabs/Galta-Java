# Demo Data

Sample datasets for demos and tests, bundled as classpath resources:

| Module | Dataset | Source / license |
|---|---|---|
| `demo-northwind` | Northwind trading company (CSV + PostgreSQL scripts) | see [demo-northwind/README.md](demo-northwind/README.md) |
| `demo-dvdrental` | DVD rental store extract (JSON) | see [demo-dvdrental/README.md](demo-dvdrental/README.md) |
| `demo-tour-de-france` | Tour de France editions since 1903 (CSV) | see [demo-tour-de-france/README.md](demo-tour-de-france/README.md) |

The data licenses are still to be confirmed: the modules are not published to
Maven Central.
