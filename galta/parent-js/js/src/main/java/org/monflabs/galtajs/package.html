GaltaJS: a JavaScript-inspired scripting engine for the JVM.

Scripts are parsed into an AST that is either interpreted or transpiled to Java source and compiled at run time. {@link org.monflabs.galtajs.JSEnvironment} is the entry point: it holds the configuration and the standard objects, and creates executable units from source code.

Extensions to JavaScript

Optional GaltaJS extensions (off by default, enabled with {@code JSEnvironment.Builder.enableGaltaJSExtensions()}) add:

  • direct access to Java classes and objects,
  • a {@code synchronized(object) { ... }} statement,
  • decimal numbers ({@code BigDecimal}, with the {@code 0m} literal suffix),
  • long integers on integer overflow,
  • JSON path operators and multi-value sequences.
