# GaltaJS Playground

The playground application for GaltaJS (`playground.GaltaJSPlayground`, packaged as the executable `target/jsplayground.jar`): the snippets of `src/main/resources/snippets`, the console, and the AST, transpiled Java and decompiled views of the current script, plus the built-in and external (Chrome DevTools Protocol) debuggers.

Shortcuts: Cmd/Ctrl+Enter executes, Cmd/Ctrl+. stops, Cmd/Ctrl+S saves. The options, window bounds and last snippet are kept in `~/.monflabs/playground-galtajs/settings.json`.
