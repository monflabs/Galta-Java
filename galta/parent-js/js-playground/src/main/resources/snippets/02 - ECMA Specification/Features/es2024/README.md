# ECMAScript 2024 (ES15)

Spec: https://262.ecma-international.org/15.0/ (15th edition)

## What's new in this release
- `Object.groupBy` and `Map.groupBy`
- `Promise.withResolvers`
- Resizable `ArrayBuffer`/`SharedArrayBuffer`, immutable ArrayBuffer slices
- `Atomics.waitAsync`
- `String.prototype.isWellFormed` / `toWellFormed`
- RegExp `v` flag (Unicode Set notation)

Only a subset of these is covered by the examples in this folder.
