# ECMAScript 2020 (ES11)

Spec: https://262.ecma-international.org/11.0/ (11th edition)

## What's new in this release
- `BigInt`
- Dynamic `import()`
- `import.meta`
- Nullish coalescing operator (`??`)
- Optional chaining (`?.`)
- `Promise.allSettled`
- `String.prototype.matchAll`
- `globalThis`
- Specified `for...in` enumeration order
- Module namespace re-export (`export * as ns from "mod"`)

The examples in this folder cover most of the above.
