# ECMAScript 2018 (ES9)

Spec: https://262.ecma-international.org/9.0/ (9th edition)

## What's new in this release
- Asynchronous iteration (`for await...of`, async generators)
- Object rest/spread properties (`{...obj}`)
- `Promise.prototype.finally`
- RegExp improvements: named capture groups, lookbehind assertions, the `s` (dotAll) flag, Unicode property escapes

The examples in this folder cover most of the above.
