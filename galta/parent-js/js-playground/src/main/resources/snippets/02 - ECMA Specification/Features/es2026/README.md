# ECMAScript 2026 (ES17)

Spec: https://262.ecma-international.org/17.0/ (17th edition)

## What's new in this release
- `Map`/`WeakMap` `getOrInsert` / `getOrInsertComputed`
- `JSON.rawJSON` / `JSON.isRawJSON`
- `JSON.parse` reviver `context.source`, giving a reviver access to a value's original source text
- `Iterator.concat(...iterables)`
- `Uint8Array` base64/hex conversion: `fromBase64`/`toBase64`, `fromHex`/`toHex`, `setFromBase64`/`setFromHex`
- `Math.sumPrecise`
- `Error.isError`
- `Array.fromAsync`

The examples in this folder cover most of the above.
