# ECMAScript 2022 (ES13)

Spec: https://262.ecma-international.org/13.0/ (13th edition)

## What's new in this release
- Class fields (public and private instance fields)
- Static class fields and static initialization blocks
- Private methods and accessors
- Ergonomic brand checks for private fields (`#x in obj`)
- Top-level `await`
- `Object.hasOwn`
- Error `cause`
- `Array.prototype.at` / `String.prototype.at` / `TypedArray.prototype.at`
- RegExp match indices (the `d` flag)

The examples in this folder cover most of the above.
