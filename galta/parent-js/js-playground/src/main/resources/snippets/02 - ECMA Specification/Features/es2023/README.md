# ECMAScript 2023 (ES14)

Spec: https://262.ecma-international.org/14.0/ (14th edition)

## What's new in this release
- `Array.prototype.findLast` / `findLastIndex`
- Change-by-copy array methods: `toReversed`, `toSorted`, `toSpliced`, `with`
- Hashbang grammar (`#!` as the first line of a script)
- `WeakMap`/`WeakSet`/`WeakRef` accept Symbols as keys/targets

The examples in this folder cover most of the above.
