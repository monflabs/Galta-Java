# ECMAScript 2019 (ES10)

Spec: https://262.ecma-international.org/10.0/ (10th edition)

## What's new in this release
- `Array.prototype.flat` / `flatMap`
- `Object.fromEntries`
- `String.prototype.trimStart` / `trimEnd`
- Optional catch binding (`catch {}` with no parameter)
- Guaranteed-stable `Array.prototype.sort`
- Revised, spec-compliant `Function.prototype.toString`
- `Symbol.prototype.description`
- Well-formed `JSON.stringify` (matches valid `JSON.parse` output for lone surrogates)

The examples in this folder cover most of the above.
