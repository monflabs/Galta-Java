# ECMAScript 2015 (ES6)

Spec: https://262.ecma-international.org/6.0/ (6th edition)

## What's new in this release
- `let`/`const` and block scoping
- Arrow functions
- Classes
- Enhanced object literals
- Template literals
- Destructuring assignment
- Default parameters
- Rest parameters
- Spread operator
- Iterators and `for...of`
- Generators
- Modules (`import`/`export`)
- `Map`, `Set`, `WeakMap`, `WeakSet`
- Promises
- Proxies and Reflect
- Symbols
- Typed arrays
- Unicode string handling (`codePointAt`, `\u{...}` escapes, ...)
- Binary and octal literals (`0b`/`0o`)
- Tail call optimization (specified; rarely implemented by engines)

The examples in this folder cover most of the above.
