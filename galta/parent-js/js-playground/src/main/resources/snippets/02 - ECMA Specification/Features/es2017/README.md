# ECMAScript 2017 (ES8)

Spec: https://262.ecma-international.org/8.0/ (8th edition)

## What's new in this release
- Async functions (`async`/`await`)
- `Object.values` / `Object.entries`
- `Object.getOwnPropertyDescriptors`
- String padding (`String.prototype.padStart`/`padEnd`)
- Trailing commas in function parameter lists and calls
- Shared memory and atomics (`SharedArrayBuffer`, `Atomics`)

The examples in this folder cover most of the above.
