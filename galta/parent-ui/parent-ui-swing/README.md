# Galta UI Swing Parent

[![Maven Central](https://img.shields.io/maven-central/v/org.monflabs.galta/parent-ui-swing?label=Maven%20Central)](https://central.sonatype.com/artifact/org.monflabs.galta/parent-ui-swing)

Parent of the Galta Swing modules.

- [ui-swing](ui-swing/README.md) - Swing components (multi-split pane, multi-line label, image panel), layouts, the FlatLaf light/dark theme and utilities (tree expansion, HiDPI scaling, idle updater)
- [ui-swing-ide](ui-swing-ide/README.md) - RSyntaxTextArea editors with find/replace/go-to dialogs, a thread-safe console stream (`TextAreaOutputStream`) and persisted UI settings
