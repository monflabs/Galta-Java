# Galta UI Parent

[![Maven Central](https://img.shields.io/maven-central/v/org.monflabs.galta/parent-ui?label=Maven%20Central)](https://central.sonatype.com/artifact/org.monflabs.galta/parent-ui)

Parent of the Galta user interface modules: a small Swing UI library, made of a
toolkit-independent layer, the Swing components and the IDE-grade editing
components used by the [playground](../parent-playground/README.md).

- [parent-ui-commons](parent-ui-commons/README.md) - the toolkit-independent modules
  - [ui-commons](parent-ui-commons/ui-commons/README.md) - value converters, lookups and the application singleton
- [parent-ui-swing](parent-ui-swing/README.md) - the Swing modules
  - [ui-swing](parent-ui-swing/ui-swing/README.md) - Swing components, layouts, the FlatLaf theme and utilities
  - [ui-swing-ide](parent-ui-swing/ui-swing-ide/README.md) - RSyntaxTextArea editors, a console stream and persisted UI settings

The API reference of each module is part of the
[API reference](https://monflabs.github.io/Galta-Java/#/API).
