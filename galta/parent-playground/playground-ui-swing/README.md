# Playground Swing UI

`PlaygroundFrame`: the snippet tree, the editors (RSyntaxTextArea, Markdown rendered with CommonMark), the console and the result tabs.

Shortcuts: Cmd/Ctrl+Enter executes, Cmd/Ctrl+. stops, Cmd/Ctrl+S saves (editable snippet libraries and the scratchpad), Cmd/Ctrl+F/R/G find, replace and go to a line in an editor.
