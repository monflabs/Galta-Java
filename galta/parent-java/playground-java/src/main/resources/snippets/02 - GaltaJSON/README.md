# GaltaJSON

The JSON library: `JsonObject` is a `Map<String,Object>` and `JsonArray` a `List<Object>`,
with typed getters and setters, a fast parser and stringifier, JSON Path, JSON Pointer and
more. The values are plain Java objects: `String`, `Number`, `Boolean`, `null` and the
containers.

Documentation: https://monflabs.github.io/Galta-Java/#/GaltaJSON/
