# Resources manifest generation for classloader based FileSystem

[![Maven Central](https://img.shields.io/maven-central/v/org.monflabs.galta.tools/filesystem-resources-manifest?label=Maven%20Central)](https://central.sonatype.com/artifact/org.monflabs.galta.tools/filesystem-resources-manifest)

A Maven plugin that generates the resource manifest used by the classpath
`ResourceFileSystem` of the Galta [`filesystem`](../../../galta/parent-utilities/filesystem/README.md)
module. A class loader cannot list its resources, so that file system reads the
list of its files from a `resources.manifest` file at its root; this plugin
writes that file from the content of a resource folder.

## Usage

```xml
<plugin>
  <groupId>org.monflabs.galta.tools</groupId>
  <artifactId>filesystem-resources-manifest</artifactId>
  <executions>
    <execution>
      <id>generate</id>
      <goals>
        <goal>generate-sources</goal>
      </goals>
    </execution>
  </executions>
  <configuration>
    <sourceDirectory>src/main/resources/snippets</sourceDirectory>
  </configuration>
</plugin>
```

The version comes from the `pluginManagement` of
[`monflabs-parent`](../../monflabs-parent/README.md), or declare `<version>`
directly. The goal (`monflabs:generate-sources`) is bound to the
`generate-sources` phase by default. `js-playground` and `playground-core` use
it for their snippet folders.

| Parameter | Default | Purpose |
|---|---|---|
| `sourceDirectory` | (required) | The resource folder to list, relative to the project's base directory |
| `manifestName` | `resources.manifest` | The manifest file name, written in `sourceDirectory` |
| `length` | `false` | Record each file's length (otherwise `-1`) |
| `date` | `2020-01-01T00:00:00Z` | The date recorded for each file: a fixed date (the default keeps the manifest stable), `now`, `file` (its last modification) or `none` |

The manifest is written **in the source folder**, not in `target/`, so it ends
up in the jar with the resources and can be committed. It lists every file
under the folder, one per line (`path<TAB>length<TAB>date`, paths relative to
the folder with `/` separators, files before subfolders), after a
`# Generated by Maven plugin` comment line; `.DS_Store`, `.gitignore`,
`.gitattributes` and the manifest itself are skipped. The file is rewritten only
when its content changes (line breaks normalized). `ResourceFileSystem` only
reads the path, before the first tab.

The jar carries an Eclipse m2e lifecycle mapping: the goal runs in the IDE on
full builds, not on incremental ones.

Without the plugin, a manifest listing only the paths works too, for example
generated with `exec-maven-plugin` and `find . -type f ! -name resources.manifest | sed 's|^./||'`.
